# Regras do projeto

- **Toda alteração** neste repositório deve ser **commitada** (`git add -A`
  + `git commit`) e **pushada** (`git push`) para o GitHub.
- Isso vale para qualquer edição, adição ou remoção de arquivo, mesmo pequenas.
- Commits devem ser concisos e em inglês (ex.: `Add game design doc`).
- Nunca deixar alterações somente locais.
